Add-in Manager
  -> Commands/GetAllSheetNamesCommand
  -> UI/Wpf/SheetManagerWindow (modeless)
  -> Infrastructure/SheetExternalEventHandler
  -> Services/Revit/SheetService

Đọc/ghi Excel: UI -> Services/Excel/SheetWorkbook -> Models/SheetInfo.
Không gọi Revit API trực tiếp từ sự kiện nút WPF hoặc background thread.
Constructor chỉ tạo UI và ExternalEvent trong IExternalCommand. Loaded + Dispatcher ContextIdle hiện màn hình tải,
sau đó QueueRequest đọc title block/sheet/floor plan/revision qua ExternalEvent. Chỉ chuyển màn hình chính khi thành công.
Lỗi tải giữ màn hình mở đầu với nút thử lại. Đóng tool hủy yêu cầu đang chờ.

PROGRESS / FILTER / DELETE
QueueSteps dùng IEnumerator<Action>, mỗi lượt xử lý một action trong ExternalEvent rồi trả quyền cho vòng UI.
Không dùng DoEvents, không chạy Revit API trên background thread, không để transaction mở giữa các lượt.
LoadProjectSteps đọc từng sheet và đổi ProcessingStatus; ImportDraftSteps kiểm tra từng dòng dữ liệu nhập.
SheetInfo INPC riêng cho ProcessingStatus; Status vẫn phục vụ validation. Done nghĩa đã nạp/kiểm tra, không nghĩa đã tạo sheet.
SheetBrowserService snapshot GetCurrentBrowserOrganizationForSheets + AreFiltersSatisfied + GetFolderItems qua API.
SheetListFilter thuần dữ liệu kết hợp search với browser visibility/full path; UI dùng ListCollectionView để giữ lựa chọn khi lọc.
SheetService.Delete kiểm tra lựa chọn bằng ID/UniqueId trước transaction và rollback nếu lỗi.

STEP 2 PROGRESS REPLACES PREVIOUS LOADING SCAN
Removed LoadProjectSteps/ImportDraftSteps and SheetInfo.ProcessingStatus; single request reads initial/import data.
FloorPlanPlacementService.Validate provides batch preflight; Place remains atomic for its supplied rows.
UI PlacePlansSteps calls Place for one sheet per request, sets Done only after commit; failed rows get Error.
Iterator disposal cancels remaining Waiting/Running entries without reverting earlier committed sheets.
